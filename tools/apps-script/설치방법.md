# 크린토피아 메일 → 감탄 캘린더 자동 등록 설치

`endrmsakdmf@gmail.com` 계정으로 로그인한 상태에서 진행합니다. (약 5분)

1. **캘린더 권한 확인**
   감탄 정산 페이지가 읽는 캘린더가 이 계정 소유가 아니라면, 소유자가
   구글 캘린더 → 설정 → 해당 캘린더 → "특정 사용자와 공유" → `endrmsakdmf@gmail.com`,
   권한 **"일정 변경"** 으로 공유합니다.
2. https://script.google.com → **새 프로젝트** → 이름을 `감탄 자동등록`으로 바꿉니다.
3. 기본 `Code.gs` 내용을 모두 지우고 `Code.gs` 파일 내용을 그대로 붙여넣습니다.
4. 맨 위 `var CAL_ID = "primary";` 줄을 고칩니다.
   - 이 계정의 기본 캘린더가 감탄 캘린더라면 그대로 둡니다.
   - 아니라면 캘린더 설정 → "캘린더 통합" → **캘린더 ID**(…@group.calendar.google.com 등)를 넣습니다.
5. 저장(💾) → 위쪽 함수 목록에서 **`setup`** 선택 → **실행**.
   권한 요청 창이 뜨면 계정 선택 → "고급" → "감탄 자동등록(으)로 이동" → **허용**.
6. 끝. 이후 10분마다 자동으로 돌아갑니다. (왼쪽 ⏰ 트리거 메뉴에 `run`이 보이면 정상)

## 사용
- **주문 배정 문자가 오면** → 10분 안에 캘린더에 `[크린토피아] 동래구 23평 아파트 (오후)` 일정이 생깁니다.
  메모에 주문번호·연락처·주소·종류·옵션이 들어갑니다.
- **작업이 끝나면**(오전 13시 / 오후 19시 이후) `[감탄] 작업인원 알려주세요 …` 메일이 옵니다.
  답장으로 적으면 일정 메모에 반영되고 "반영했습니다" 답장이 옵니다.
  - `3` → 작업인원: 3명
  - `2명 추가 50000` 또는 `2명 추가금 5만` → 작업인원 + 카톡방에서 확인한 추가금
- **형식이 다른 크린토피아 메일**(변경·취소 등)은 일정을 만들지 않고
  `[감탄] 확인 필요` 메일로 알려 줍니다. 이건 캘린더에서 직접 고쳐 주세요.
  (변경·취소 문자 예시를 주시면 이것도 자동 처리하게 바꿀 수 있습니다.)

## 문제가 생기면
- script.google.com → 프로젝트 → 왼쪽 **실행** 메뉴에서 오류 내용을 확인합니다.
- "캘린더를 찾을 수 없음" 오류: 4번의 캘린더 ID 또는 1번의 공유 권한을 확인하세요.
