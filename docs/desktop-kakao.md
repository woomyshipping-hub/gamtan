# 데스크톱 Claude: 카톡 → 캘린더 예약 작업

상시 켜 둔 데스크톱의 Claude 데스크톱 앱(컴퓨터 사용 켜짐)에 예약 작업으로 등록한다. 클라우드 세션에서는 컴퓨터 사용이 안 된다.

## 준비
1. Claude 데스크톱 앱 → 설정 → 컴퓨터 사용 켜기, 카카오톡 PC 로그인 유지
2. 데스크톱에 토큰 파일 저장: 터미널에서 `echo '<INBOX_TOKEN 값>' > ~/.gamtan_inbox_token && chmod 600 ~/.gamtan_inbox_token`
3. 예약 작업: 30분마다 (예: 매일 07:00~22:00)

## 예약 작업 문구
```
카카오톡 PC 앱에서 "김동현 홈클린마스터" 채팅방을 열고 최근 메시지를 읽어줘. 메시지는 읽기만 하고 절대 보내거나 지우지 마.

1. 화면에 보이는 최근 2일치 메시지를 위에서부터 순서대로 모아. 메시지마다 보낸 사람, 보낸 날짜와 시각(한국 시간), 내용 전체를 그대로 옮겨. 한 사람이 여러 줄로 보낸 일정 메시지는 하나로 합쳐.
2. ~/.gamtan_inbox_token 파일의 값을 토큰으로 써서, 메시지를 5개씩 나눠 아래 형식으로 보내. 이미 보낸 메시지를 다시 보내도 서버가 알아서 무시하니 겹쳐도 된다.
   curl -s -X POST https://gamtan-kr.netlify.app/api/inbox -H "Authorization: Bearer <토큰>" -H "Content-Type: application/json" -d '{"source":"kakao","chat":"김동현 홈클린마스터","messages":[{"sender":"보낸 사람","sent_at":"2026-11-08T16:11:00+09:00","text":"내용"}]}'
3. 응답에 "deferred"가 1 이상이면 1분 뒤 마지막 묶음을 한 번 더 보내.
4. 끝나면 응답의 created / extra_applied / unmatched / error 숫자만 한 줄로 남겨. 토큰 값은 어디에도 출력하지 마.
```

## 서버 처리 (요약)
- 새 일정 → 정산 캘린더에 `[자체영업] 지역 N평 건물 (오전|오후)` 등록 (같은 날·시간대 일정이 있으면 건너뜀)
- "오전/오후 추가 N원있습니다", "추가 없습니다" → 그날 해당 일정 메모에 `추가금: N원`
- 자세한 규칙: [M1.md](./M1.md) "카톡 → 캘린더"
